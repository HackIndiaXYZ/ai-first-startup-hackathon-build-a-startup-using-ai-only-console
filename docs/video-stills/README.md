# RecallScope video source captures

These images were captured from the live RecallScope application and the official repository on 13 September 2026 (Asia/Kuala_Lumpur). They are source assets for the narrated product video; app screens have not been generated or redrawn.

The first trace uses the supplied bakery sample: FL-260901-A, four batches, four destinations and 1,440 delivered packs. Its report was created during capture as RS-702FF6BC and remained available after reload.

The AI intake sequence used the included [example document](../../sample-records/showcase/ai-intake-example.txt) in a real Fireworks request. It returned three proposals. During source review, the blank production lot reference was filled with AL-260913-A exactly as printed in the original. After approval, the new lot traced to one batch, one customer and 180 delivered packs. This is an authored example, not a manufacturer trial or a general extraction-accuracy claim.

The narration and edit use these captured states with authored crops, transitions and motion graphics. They do not represent a continuous real-time recording or a performance benchmark. The pitch frame comes from the editable project deck.
